# try2reverse
Try to reverse engineer bale and create your custom client and win the 100K prize!

bale is a messaging app like telegram, you can login and chat with your friends, and it's going to be open sourced after this challenge.

your starting package is bale.rar, extract it and start digging!

submit your client source code and a build to 
try2reverse@bale.ir
note: you must extract every protobufs, protocols, lifecycle, urls, ....
and your client must be as useable as a real one.

accepted languages: Java, C#, Kotlin, Python
